# K Lohith - Professional Developer Portfolio

A dynamic, glassmorphism-styled personal portfolio built with React and Vite. It showcases my skills, experience, and projects as a Full Stack Developer.

## Repository
[https://github.com/Lohith1807/my-profile](https://github.com/Lohith1807/my-profile)

## Features
- **Dynamic Orbital Skills Animation:** A custom CSS animation system highlighting my core tech stack (React, Node.js, Python, MongoDB, MySQL, etc.) using smooth counter-rotating rings.
- **Glassmorphic UI:** Modern aesthetic using background blurs, subtle borders, and smooth transitions.
- **Interactive Projects Modal:** Clickable project cards that open detailed modal overlays with descriptions, tags, and links to GitHub and Live Demos.
- **Compact Social Links:** Direct, beautifully styled pill buttons for fast communication via WhatsApp, LinkedIn, Instagram, Gmail, and Outlook.
- **Responsive Layout:** fully optimized for mobile, tablet, and desktop viewing.

## Tech Stack
- **Frontend:** React, Vite, HTML5, Vanilla CSS
- **Icons:** FontAwesome

## Local Development Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Lohith1807/my-profile.git
   ```

2. **Navigate to the directory**
   ```bash
   cd my-profile
   ```

3. **Install Dependencies**
   ```bash
   npm install
   ```

4. **Run the Development Server**
   ```bash
   npm run dev
   ```
